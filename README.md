# মাহাবুব কম্পিউটার্স — বাংলা One Page Portfolio

## ফাইল
- `index.html`: ওয়েবসাইটের কনটেন্ট, SEO ও LocalBusiness তথ্য
- `style.css`: Purple Gradient ডিজাইন ও responsive layout
- `script.js`: মোবাইল মেনু ও footer year
- `CUSTOM_PROMPT.md`: ভবিষ্যতে সম্পাদনা/পুনর্নির্মাণের prompt

## লোকাল কম্পিউটারে চালানো
ZIP extract করে `index.html` ব্রাউজারে খুলুন। কোনো npm install বা build step নেই। কোড সম্পাদনায় VS Code ব্যবহার করতে পারেন।

## ইমেইল ফর্ম
ফর্মটি FormSubmit দিয়ে `mahabubcomputers@gmail.com`-এ ইমেইল পাঠানোর জন্য সেট করা। সাইট প্রকাশ করে প্রথমবার ফর্ম সাবমিট করুন; FormSubmit-এর verification email এলে নির্দেশনা অনুসরণ করুন। তারপর আবার পরীক্ষা করে Inbox/Spam দেখুন। এটি তৃতীয় পক্ষের সেবা—তাদের বর্তমান শর্ত ও গোপনীয়তা নীতি দেখুন। সংবেদনশীল নথি/পাসওয়ার্ড পাঠাবেন না। বাস্তবে ব্যবহারের আগে ফর্ম পরীক্ষা করা আবশ্যক।

## Google Maps
বর্তমান লিংকটি ঠিকানা দিয়ে Maps-এ সার্চ করে, নিশ্চিত GPS pin নয়। সঠিক দোকানের Google Maps Place খুলে Share → Copy link নিয়ে `index.html`-এর `class="map"` লিংকের `href` পরিবর্তন করুন।

## GitHub Pages hosting
1. GitHub-এ repository তৈরি করুন এবং এই ফাইলগুলো upload করুন।
2. Settings → Pages → Deploy from a branch নির্বাচন করুন।
3. `main` branch এবং `/(root)` নির্বাচন করে Save করুন।
4. সাইট প্রকাশ হলে URL খুলে মোবাইল মেনু, ফোন, WhatsApp, Maps ও contact form পরীক্ষা করুন।
5. ফোন/ইমেইল/ঠিকানা এবং সেবার বিবরণ যাচাই করে প্রকাশ করুন।

নোট: এই package তৈরি হয়েছে; কিন্তু এখানে live hosting, third-party form delivery বা বাস্তব ডিভাইসে production test করা হয়নি।
